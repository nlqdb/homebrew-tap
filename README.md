# nlqdb/homebrew-tap

Homebrew tap for the nlqdb CLI.

```bash
brew install nlqdb/tap/nlq
```

## Formulas

| Formula | Status | Description |
| :------ | :----- | :---------- |
| `nlq`   | _pre-alpha_ | CLI for [nlqdb](https://github.com/nlqdb/nlqdb) — a database you talk to. |

Formulas are not published here yet. This repo exists to reserve the
tap name and will be populated when the Go CLI ships (IMPLEMENTATION.md
§5, Phase 2).

Source of truth lives in `nlqdb/nlqdb`'s `cli/` directory. Releases
publish new formula versions here via the reusable `release.yml`
workflow defined in the main repo.
